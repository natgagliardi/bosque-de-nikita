# El Bosque de los Duendes de Nikita

Primera versión visual de la home para una tienda de duendes artesanales.

## Estructura

- `index.html` — Home completa
- `css/styles.css` — paleta, tipografía, layout, responsive y detalles
- `js/app.js` — luciérnagas y pequeñas interacciones
- `assets/` — espacio para fotos, ilustraciones y texturas reales

## Próximo paso

Reemplazar los emojis/placeholder de los productos por las fotografías reales de los duendes y conectar cada tarjeta con la ficha de producto.

La estructura está pensada para que luego pueda adaptarse a una implementación de Tiendanube.
